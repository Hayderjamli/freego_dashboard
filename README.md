# mobile_app_dashboard

Simple Flutter dashboard that visualises temperature, humidity, and door usage trends for a monitored room.

## Features
- Overview landing page with quick status for temperature, humidity, and door activity.
- Temperature and humidity charts showing the last 24 hours (sample data).
- Bar chart tracking door openings and closures throughout the day.
- Live door status tile summarising whether the door is open or closed and the latest totals.
- Responsive layout that adapts between one, two, or three columns depending on the screen width.
- Refined blue/gray visual theme with animated tiles and glassmorphism-inspired cards.

## Run Locally
```powershell
flutter pub get
flutter run
```

## Tests
```powershell
flutter test
```
